# Página del primer evento e identidad del club

Carles limita el trabajo actual a los puntos 1 y 2 de la propuesta SEO: página propia del primer encuentro y coherencia de identidad. Descarta conseguir enlaces de colaboradores y deja crónica y medición periódica para después del evento. No se promete una posición en Google.

La ficha estará en `/eventos/descubriendo-perfumes-nicho/`, enlazada desde la portada, con HTML prerenderizado, cartel, descripción, fecha, horario, lugar, organización, navegación de vuelta y acceso a Luma. Cada URL tendrá metadatos y canonical propios y figurará en el sitemap. Se conserva el titular de portada, el burdeos y marfil, la cabecera y las redes fijas y el scroll central. No se añaden dependencias.

Se centraliza la identidad oficial (nombre, dominio y enlaces) para los datos estructurados Organization y WebSite y para la ficha. Luma confirma el 29 de octubre el mismo nombre, dominio y handles. No hay herramientas conectadas para modificar los perfiles de Instagram o TikTok; no se atribuirán cambios externos que no se hayan realizado.

El evento está en lista de espera en Luma al comprobarlo. La web remite allí para la disponibilidad, sin afirmar que quedan plazas. Se mantiene el aviso destacado de registro obligatorio y plaza confirmada. No se ofrece admisión inmediata ni se debilita esta condición para optar a resultados enriquecidos de eventos. La ficha se identifica como WebPage con BreadcrumbList; se pospone Event orientado a rich results mientras haya restricción de acceso mediante confirmación.

Enfoque elegido: extender la generación estática existente para producir las dos páginas. Añadir un router cliente o un CMS incorporaría complejidad innecesaria para esta ficha; el HTML generado puede publicarse directamente en GitHub Pages.

Validación: acceso directo y por enlace, navegación de retorno, HTML sin JavaScript, canonical y metadatos únicos, sitemap, datos estructurados coherentes, cartel cargado, aviso, enlaces y accesibilidad en móvil y escritorio. Se actualizan documentación y memoria del alcance aprobado.
