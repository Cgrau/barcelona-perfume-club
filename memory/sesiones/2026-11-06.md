# Claude SEO y datos reales de Google

Carles pide usar Claude SEO en este proyecto y aporta el ZIP de Performance de Search Console exportado el 6 de noviembre. Se identifica el proyecto oficial [AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo), MIT, versión 2.5.0. Se instala con el CLI oficial y alcance `project`; `claude plugin list --json` confirma plugin habilitado. La configuración portable queda en `.claude/settings.json`. Se usa la URL del marketplace en minúsculas para resolver un conflicto de mayúsculas de la caché en macOS, sin tocar otros plugins.

La instalación del plugin no configura por sí sola su entorno Python/Chromium. `doctor --json` da `ready: false` y `browser_ready: false`. Su skill principal limita esa configuración a una petición explícita `/seo setup` o de reparación de dependencias. La auditoría actual aplica las guías con HTTP, Python estándar, Playwright/Brave y Lighthouse existentes, sin conectar APIs privadas ni servicios de pago. No se presenta como ejecución de todos sus scripts. [Guía de uso desde Claude Code y otros agentes](../../docs/seo/README.md).

No se infiere ausencia de demanda de consultas ocultas, ni exclusión de las páginas interiores por no figurar en rendimiento. No se convierte el 3,67 en una posición para las tres consultas objetivo de [[Decisiones]], ni desde Barcelona. El clic del 28 de octubre precede a los ajustes del 29; los otros dos son del 3 de noviembre. No se atribuye causalidad ni se concluyen tendencias con esta muestra.
