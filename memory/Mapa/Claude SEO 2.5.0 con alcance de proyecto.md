# Claude SEO 2.5.0 con alcance de proyecto

<!-- project-memory:start -->
Plugin oficial AgriciDaniel/claude-seo, MIT, instalado y habilitado en Claude Code con alcance project y configuración portable .claude/settings.json. No registra automáticamente skills en Codex. Guía docs/seo/README.md. Entorno propio Python/Chromium sin configurar: doctor ready:false y browser_ready:false. /seo setup requiere petición explícita; se aplican guías con HTTP, Python estándar, Playwright/Brave y Lighthouse existentes, sin servicios de pago ni presentar todos los scripts como ejecutados.
